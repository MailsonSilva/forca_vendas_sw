Query de Busca Oficial na finrecdup00Para cobrir tanto o nome exato da tabela quanto possíveis variações no nome da coluna de cliente entre versões do banco, a busca deve consultar a finrecdup00 (com fallback para finrecdup se aplicável):SQLSELECT
    d.dup00_codigo AS titulo,
    d.dup00_datemi AS emissao,
    d.dup00_datven AS vencimento,
    COALESCE(d.dup00_valori, 0.0) AS valor_original,
    COALESCE(d.dup00_valdev, d.dup00_valori, 0.0) AS saldo_devedor,
    COALESCE(d.dup00_valpag, 0.0) AS valor_recebido,
    COALESCE(d.dup00_valjur, 0.0) AS valor_juros,
    COALESCE(d.dup00_codven, 0) AS vendedor,
    COALESCE(d.dup00_codagt, 0) AS agente_cobrador,
    COALESCE(d.dup00_codcob, 0) AS tipo_cobranca
FROM finrecdup00 d
WHERE CAST(COALESCE(d.dup00_codcli, d.dup00_clicod) AS INTEGER) = CAST(:codcli AS INTEGER)
  AND COALESCE(d.dup00_valdev, d.dup00_valori) > 0
ORDER BY d.dup00_datven ASC;
